Renommer son document

Un document rendu doit s'appeler NOM_Prenom_Activite.pdf : ton nom en majuscules, ton prénom, le nom de l'activité, séparés par des tirets bas, sans accent ni espace. Tape tes informations : le nom de fichier à utiliser s'affiche.

NOM_Prenom_Activite.pdf

Renommer un fichier sous Windows

  1. Ouvre l'Explorateur de fichiers et va dans le dossier Téléchargements (ou là où tu as enregistré ton fichier).
  2. Clique une fois sur le fichier pour le sélectionner, puis appuie sur la touche F2 (ou clic droit › Renommer).
  3. Colle le nom copié ci-dessus (Ctrl + V). Ne touche pas à l'extension (.pdf) si elle est affichée.
  4. Valide avec Entrée, puis dépose le fichier sur le Nuage de la classe.

Sur Mac : sélectionne le fichier, appuie sur Entrée pour renommer. Dans les activités en ligne de ce site, le nom correct est proposé automatiquement au moment de l'export PDF.
