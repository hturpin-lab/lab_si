Dépose les PDF des élèves et le ou les corrigés machine (.json) n'importe où sur la page.

    Choisis une copie dans la liste.

    Mode d'emploi

    1. Télécharge le dossier des rendus depuis le Nuage, puis dépose les PDF (ou le dossier) ici.
    2. Charge le corrigé machine de chaque activité (fichiers cle_….json, gardés sur ton ordinateur : jamais sur le site).
    3. Rendus : qui a rendu quoi, doublons, PDF sans données.
    4. Correction : chaque question est proposée : juste ½ (formule juste / partiel) faux non traité sont acceptées d'office (tu peux changer) ; à trancher attend ta décision. Clique 0, ½ ou 1 ; ajoute un commentaire si besoin.
    5. Ressemblances : 0 à 100 entre élèves, sur les réponses fausses ou personnelles (les réponses justes communes ne comptent pas).
    6. Alertes : texte collé, nom refusé, PDF ou fichier .json retouché.
    7. Exporter : classeur avec notes, détail, questions ratées, non faits, ressemblances et alertes. Sauvegarder la session garde tes décisions (sans les PDF) pour reprendre plus tard.

    Les PDF faits avant le 19/11/2026, imprimés autrement ou scannés n'ont pas de « Données de contrôle » : l'outil affiche alors la copie et toutes les questions sont « à trancher ».

    Aucune donnée n'est envoyée sur internet : les PDF sont lus dans ce navigateur (bibliothèques pdf.js et SheetJS incluses dans le site). Les décisions sont gardées dans ce navigateur.
